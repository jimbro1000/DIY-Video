# How to get involved #

The primary path for contributing to this project is to join
me on the Retro Hardware Discord where I have a dedicated
content creator channel under the name jimbro1000. From here
I can coordinate effort.

The alternative is to take a fork of the project to create
changes, fixes, improvements, etc. and then raise a pull
request. Unfortunately, due to how KiCad works this is
rarely a trivial process but with the schema separated into
separate documents there is some hope that this does not
fall into an integration nightmare. Ultimately any changes
will need hand crafting back into the design rather than a
traditional code merge, hence why this is the alternative
choice.

## Adapting for alternative designs ##

This is an open source project, there is nothing stopping
you using it for your own design, in whole or in part. If
you do create an improvement, new module, or new sub-system,
please contact me with the details so it can be incorporated

As a side project, I intend to keep specific system integrations
together to help others use the design more easily
